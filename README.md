### 🧬 Hybrid Physiological Agent Based Modelling of Type 2 Diabetes Mellitus

**Research Problem:** Develop a mathematical and computational framework to investigate Type 2 diabetes progression by integrating physiological glucose insulin dynamics with population level heterogeneity in individual characteristics and behavioral patterns.

**Approach:** Developed a hybrid model combining six coupled ordinary differential equations describing glucose, insulin, pancreatic beta-cell mass and insulin sensitivity with an agent based population framework. Incorporated probabilistic physiological parameters, individual initial conditions and age dependent behavioral inputs, including caloric intake and physical activity.

**Tools:** Python • JAX • NumPy • Diffrax • Optax • NHANES 2003–2004 survey data

**Skills:** Mathematical Modelling • Agent Based Modelling • Statistical Modelling • Probabilistic Simulation • Parameter Calibration • Numerical Methods • Computational Biology • Health Data Analysis

**Key Findings:** The model reproduced important features of metabolic progression, including compensatory insulin responses and declining insulin sensitivity. Population heterogeneity emerged from variations in physiological parameters, initial conditions and behavioural inputs. Distributional calibration enabled comparison of simulated glucose and insulin distributions with empirical age-group observations. Sensitivity experiments indicated that initial conditions primarily influenced variability, while behavioural inputs affected both average progression and outcome dispersion.

➡️ [View Research Repository](https://github.com/Yvonneamg/Modelling-the-epidemiologic-evolution-of-Diabetes-Mellitus-Integrating-Physiological-Agent-models)


### 📊 Data Professionals Survey Analysis

**Research Problem:** Analyse survey responses from data professionals to identify trends in salaries, professional roles, preferred programming languages and workplace satisfaction.

**Approach:** Analyzed survey data from 630 respondents across 28 columns using Power BI and Power Query. Cleaned and transformed the raw Excel dataset by removing unnecessary columns, standardizing responses, splitting columns, correcting data types and creating calculated columns. Developed interactive visualizations to communicate key findings about salaries, programming language preferences, demographics and job satisfaction.

**Tools:** Power BI Desktop • Power Query • Excel

**Skills:** Data Cleaning • Data Transformation • Exploratory Data Analysis • Data Visualisation • Business Intelligence • Power Query (M Language) • Dashboard Development

**Key Findings:**
- **630 individuals** participated in the survey, with an average respondent age of approximately **30 years**.
- **Data scientists** reported the highest average salary, at approximately **93.78**.
- **Python** was the most preferred programming language among data professionals, with **225 data analysts** identifying it as their favourite.
- Average work-life balance satisfaction was **5.74 out of 10**.
- Average salary satisfaction was **4.27 out of 10**.
- 
**Visualisations:** Used cards, bar and column charts, a tree map, gauge charts and donut charts to present the findings in an interactive Power BI dashboard.

➡️ [View Project Repository](https://github.com/Yvonneamg/Data_Professionals_Survey_Analysis)
